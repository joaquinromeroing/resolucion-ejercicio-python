# Busqueda Binaria

Ejercicio: carga interactiva de numeros enteros (rango 1 a 100000, fin con 0),
ordenamiento por metodo Burbuja y busqueda binaria sobre el arreglo resultante.

## Estructura

- `algoritmos.py` — funciones `burbuja` y `busqueda_binaria`.
- `main.py` — programa interactivo (carga, ordena, busca).
- `test_algoritmos.py` — unit tests con `unittest` (stdlib, sin dependencias).

## Como ejecutar

```bash
python3 main.py
```

## Como correr los tests

```bash
python3 -m unittest test_algoritmos.py -v
```
