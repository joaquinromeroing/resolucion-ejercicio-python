# Busqueda binaria y ordenamiento burbuja

Solucion en Python para:
- Cargar numeros enteros por teclado con validacion de rango.
- Ordenar los numeros con burbuja.
- Buscar un numero con busqueda binaria.
- Ejecutar pruebas unitarias con pytest.

## Ejecutar

```bash
python main.py
```

## Probar

```bash
pytest
```
